# Clone Blocker

**Tiếng Việt** · [English](README.en.md)

Chặn không xuể lũ clone, bot, bò đỏ? Đã có Clone Blocker.
Tiện ích này sẽ tải danh sách clone từ nguồn dữ liệu được đóng góp bởi cộng đồng (và chính bạn), sau đó sẽ từ từ block tất cả giúp bạn một cách tự động mà không cần làm tay từng cái một.

## Cài đặt

**[Cài đặt từ Chrome Web Store](https://chromewebstore.google.com/detail/clone-blocker/mlkbihlabbmjdhmadjkijioafknfnmaj)** — miễn phí


Cần Chrome 120 trở lên.

<details>
<summary>Hoặc cài từ mã nguồn</summary>

Mở `chrome://extensions`, bật **Chế độ dành cho nhà phát triển**, chọn **Tải tiện
ích đã giải nén** rồi trỏ vào thư mục.

</details>
