# Chrome Web Store badge

`chrome-web-store-badge-496x150.png` (496×150) is Google's official "Available
in the Chrome Web Store" badge, the **bordered** variant at its largest size,
taken unmodified from <https://developer.chrome.com/docs/webstore/branding>.

It is committed here rather than hot-linked, and the reason is not only that
somebody else's CDN can fail or be slow. **Hot-linking hands the address of
everybody who reads this page to a third party.** This project exists so people
can report accounts impersonating them — including state-aligned ones — and
GitHub's own image proxy is not something to rely on for that.

**Do not edit this file.** Google's guidelines permit resizing that preserves
the proportions and nothing else, and the alt text has to stay "Available in
the Chrome Web Store". The README renders it at `width="150"`, which is a clean
downscale of the same shape.

One file, not a 1x/2x pair. The medium badge is 340×96 and the large is
496×150 — ratios 3.54 and 3.31 — so they are not the same shape, and pairing
them in a `srcset` would render a differently-proportioned badge depending on
the reader's screen density. That is the "preserve the proportions" rule being
broken by the mechanism meant to serve it.

The dimensions are in the filename on purpose: a name that changes when the
bytes change means a replaced asset is a new URL and there is nothing to purge
from any cache in front of it.

The site keeps its own copy at `hosting/img/` in the backend repository, with a
longer note about why it sits under the call to action rather than being it.
The two files are byte-identical and neither is generated from the other.
